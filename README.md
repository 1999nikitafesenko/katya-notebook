# Катин блокнот

Учёт денег по конвертам, списание тренировок клиентам и календарь дел. Веб-приложение для телефона: открыть в Safari → «Поделиться» → «На экран Домой».

Данные хранятся только на телефоне (в браузере). Резервная копия: вкладка «Ещё» → «Сохранить копию».

## Как обновлять

Исходник — `src/katya.html`. После правок пересобрать сайт:

```
python3 build.py
```

Скрипт генерирует `index.html`, иконки, `manifest.webmanifest` и `sw.js` в корне репозитория (их публикует GitHub Pages).
